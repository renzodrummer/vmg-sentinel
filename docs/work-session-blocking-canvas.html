Work-session blocking (helper fw-4)

Unelevated Electron sends signed policy and session on/off over a named pipe. The LocalSystem helper enforces only while tracking is on: Firewall for sites, AppLocker deny-list (Allow Everyone * plus listed denies) for app launch.

Two engines, one clock Sites lose outbound connectivity (any browser or curl). Listed apps cannot CreateProcess, and already-running matches are closed once. Stop Tracking deletes both rule sets. AppLocker is never applied as deny-only — that fw-3 pattern locked Task Manager and other apps.

What each layer owns

Angular. Banner, Start/Stop Tracking. Never opens the pipe.

Electron main. Work-session gate, Ed25519 policy, pipe client only.

Helper. Verify policy, DNS, INetFw, AppLocker XML, one-shot close.

OS. Firewall drops packets. AppLocker refuses launch.

Session gate

Enforcement requires helper LocalSystem (or admin), a signed policy in block mode, and an active work session.

session off → clear rules policy missing → idle session + policy → fw + AppLocker
